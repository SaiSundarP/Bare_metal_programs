> A curated collection of embedded systems projects, experiments, and firmware implementations focused on understanding hardware from the ground up.

This repository serves as a practical learning platform for bare-metal programming, RTOS-based development, peripheral interfacing, device drivers, communication protocols, and real-world embedded applications across various microcontroller families.

---

## 🎯 Repository Goal
To build a strong foundation in embedded systems engineering through hands-on development, low-level hardware interaction, and real-world firmware projects while strictly following industry-standard design and coding practices.

---

## 💻 Supported Platforms
We experiment and build across a diverse range of microcontroller architectures:
* **Espressif:** ESP8266, ESP32
* **STMicroelectronics:** STM32 Series
* **Microchip/Atmel:** AVR (ATmega Series)
* **ARM:** Cortex-M Microcontrollers
* **Maker Boards:** Arduino-Compatible Boards & other dev platforms

---

## 🔬 Core Areas of Focus

### 🛠️ Bare-Metal Programming
* Register-level programming
* GPIO configuration and control
* Interrupt handling & Vector Tables
* Timers, counters, and clock configuration
* Memory-mapped peripherals

### ⏱️ Real-Time Operating Systems (RTOS)
* **FreeRTOS fundamentals**
* Task scheduling & Preemption
* Inter-task communication (Queues)
* Synchronization (Semaphores & Mutexes)
* Event groups & Software timers

### 🔌 Peripheral Interfacing
* **Serial:** UART, SPI, I2C
* **Analog:** ADC, DAC
* **Signal:** PWM, GPIO Interrupts

### 📡 Communication & Connectivity
* **Wireless:** Wi-Fi, Bluetooth
* **Protocols:** MQTT, TCP/IP, HTTP/HTTPS, Serial Communication

### ⚙️ Device Drivers
* Sensor and display drivers
* Communication drivers
* Custom Hardware Abstraction Layers (HAL)

### 🚀 Embedded Applications
* IoT & Monitoring Systems
* Automation & Safety Projects
* Robotics & Wearable Devices
